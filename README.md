# Brand Store — магазин брендовой одежды

Три компонента:

1. **Shopify-магазин** — витрина, товары от поставщика BrandsGateway (склады EU и US).
2. **Телеграм-группа + бот** — менеджер пишет `Название | Наша цена | Дизайнер`,
   бот находит товар на официальном сайте дизайнера, отвечает карточкой
   (фото, описание, цена бренда зачёркнута, наша цена с пометкой «выгоднее на N%»)
   и **создаёт черновик товара в Shopify**: наша цена — цена товара,
   цена с сайта бренда — compare-at («до скидки», зачёркнутая на витрине).
   Менеджер проверяет черновик и публикует.
3. **Сервер** (`server/`) — общий бэкенд: сейчас поиск+парсинг для бота,
   дальше сюда же ляжет интеграция с Shopify.

## Как работает поиск товара

```
Менеджер в ТГ ──▶ Бот (grammY) ──┐
Shopify и др.  ──▶ HTTP API ─────┤──▶ findProduct()
                                      │ 1. дизайнер → официальный домен (src/search/brands.ts)
                                      │ 2. поиск: Serper (Google API) или DuckDuckGo (бесплатно)
                                      │ 3. загрузка страницы товара
                                      │ 4. парсинг JSON-LD (schema.org Product) / OpenGraph
                                      ▼
                       Карточка: фото + цена бренда vs наша цена
```

Бот и HTTP API живут в одном процессе (`npm run start`) — один хостинг, одна кодовая база.

### HTTP API

- `GET /health` — проверка живости (для хостинга/мониторинга).
- `POST /api/lookup` — поиск товара:

```json
// запрос
{ "title": "Re-Nylon backpack", "designer": "Prada", "ourPrice": 990, "currency": "EUR" }
// ответ 200: { "found": true, "product": {…}, "comparison": {…} }
// ответ 404: { "found": false }
```

JSON-LD-разметка есть почти у всех брендов (Gucci, Prada, Balenciaga…), поэтому
один парсер покрывает большинство сайтов без индивидуальных скраперов.

## Запуск бота

1. Создать бота у [@BotFather](https://t.me/BotFather): `/newbot` → получить токен.
2. **Отключить privacy mode**, чтобы бот видел обычные сообщения в группе:
   `/setprivacy` → выбрать бота → `Disable`. (Иначе работать будет только `/check`.)
3. Добавить бота в группу менеджеров.
4. В `server/`: скопировать `.env.example` → `.env`, вписать `BOT_TOKEN`.
5. (Желательно) ключ с [serper.dev](https://serper.dev) в `SERPER_API_KEY` —
   2500 бесплатных запросов Google-поиска; без него работает DuckDuckGo.
6. `npm install`, затем `npm run dev`.

Проверка поиска без Телеграма:

```
npm run lookup -- "GG Marmont small shoulder bag | 1490 | Gucci"
```

## Открытые вопросы

1. **BrandsGateway «отдавать 1»** — что именно имелось в виду? Похоже на
   «остаток = 1 шт. на позицию» (нормально для люксового дропшиппинга), но лучше уточнить.
2. **Хостинг сервера** — Railway/Render (~$5/мес) или уже есть VPS?
3. **Serper-ключ** — завести аккаунт на serper.dev (бесплатно) для надёжного поиска.
